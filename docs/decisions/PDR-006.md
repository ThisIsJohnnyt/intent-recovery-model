# PDR-006: License the gold dataset CC BY-NC-SA 4.0, not CC-BY-4.0

**Date**: 2026-08-12
**Status**: Accepted

## Decision

`datasets/gold/` (the hand-curated gold-tier corpus) is licensed **CC
BY-NC-SA 4.0** (Attribution-NonCommercial-ShareAlike), replacing the
CC-BY-4.0 license it carried since 2026-07-28. Anyone may access, use,
fork, refine, and share the dataset for noncommercial purposes; any
distributed derivative must remain noncommercial and carry the same
license (ShareAlike); attribution to ThisIsJohnnyt is required.

This is a **project-wide policy**, not a dataset-specific one: the project
and all downstream forks are intended to remain permanently noncommercial,
public, and attribution-required, **prospectively — from 2026-08-12 forward**
(see "Historical CC-BY-4.0 exception" below for why that qualifier is load-
bearing, not boilerplate). This PDR records the dataset license as the
first concrete artifact updated to match; the code, documentation, and
model-weight licenses are separately gated (see Scope below) and are not
decided by this record.

Because a NonCommercial restriction is incompatible with the Open Source
Initiative's Open Source Definition (criterion 6, no discrimination against
fields of endeavor), project materials should describe this posture as
**source-available/noncommercial**, not "open source" in the OSI sense —
even though it matches the plain-language meaning the product owner has
used throughout this project ("free for anyone to use/fork/refine/share").

## Reasoning

`datasets/gold/LICENSE.md` was set to CC-BY-4.0 in `1cb3490` ("Restructure
dataset into a documented, research-quality corpus", 2026-07-28) — a
repo-restructuring commit, not backed by any PDR or deliberate commercial-
use decision. CC-BY-4.0 permits unrestricted commercial reuse by anyone,
including forks, which conflicts with the product owner's actual intent.

The conflict surfaced during independent review of
`training/intent_recovery_data_model_discovery_plan_chatgpt.md` (the
external dataset/model-capability discovery plan ChatGPT drafted): that
review required pinning down the project's actual licensing posture to
evaluate whether NC-licensed external candidates (e.g. DialogSum, CC
BY-NC-SA 4.0) were compatible with the project's goals. Asking the question
surfaced that the committed dataset license didn't match the product
owner's real intent once stated explicitly — an instance of `NORTH_STAR.md`'s
"Repository Authority" principle: repository state and conversational
intent had quietly diverged, and the discrepancy needed surfacing rather
than silent resolution in either direction.

The product owner's confirmed intent (2026-08-12): the project and all
downstream forks remain noncommercial; anyone may access, use, fork,
refine, and share it for noncommercial purposes; downstream forks must
preserve the noncommercial restriction; attribution returns to the product
owner for the original creation. CC BY-NC-SA 4.0 is the closest standard
license to that intent — NonCommercial matches the restriction, ShareAlike
is the actual legal mechanism that forces forks to preserve it (a plain
CC BY-NC 4.0, without ShareAlike, would stop commercial use but would not
require a fork to relicense its derivative under the same terms).

## Historical CC-BY-4.0 exception (prospective effect only)

This decision is prospective, not retroactive, and cannot be otherwise: CC
licenses are irrevocable once granted (CC BY 4.0 legal code §2(a)(1); CC's
FAQ confirms "once something has been published under a CC license,
licensees may continue using it according to the license terms"). A
licensor may stop distributing under the old license or offer new terms
later, but per §6(c) of the CC BY 4.0 legal code, "doing so will not
terminate this Public License."

`datasets/gold/` was genuinely published under CC-BY-4.0 from `1cb3490`
(2026-07-28) through `2f7a101` (`gold_v1.2.3`, 2026-08-03) — both confirmed
as real ancestors of the public `origin/main`, meaning anyone who cloned or
forked the repository during that roughly two-week window received those
files under CC-BY-4.0's actual terms, including the right to use them
commercially. That grant cannot be revoked by this PDR, by
`datasets/gold/LICENSE.md`'s new text, or by any later project decision.

**What this means concretely:** "permanently noncommercial, all downstream
forks" (above) is accurate for material first published 2026-08-12 or
later. It is not accurate, and this PDR does not claim it is, for whoever
already holds a CC-BY-4.0 copy from the earlier window — those recipients
keep their CC-BY-4.0 rights for that copy indefinitely. This project does
not rewrite history, delete the affected releases, or represent that those
already-granted rights can be withdrawn.

## Scope

This decision covers only `datasets/gold/` (and, by extension, whatever
`DATASET_SPEC.md` documents as living there). It does **not** license:

- the project's code (training/inference scripts, `training/*.py`) — no
  license currently exists for this at all, at any level;
- documentation;
- released model weights (`intent-recovery-model-*` releases).

Those remain open questions, tracked in
`training/intent_recovery_data_model_discovery_plan_chatgpt.md`'s framing
that "exact license selection remains a separate decision requiring
compatibility and rights review." CC licenses are generally not recommended
for software (per Creative Commons' and GitHub's own guidance); a
NonCommercial-compatible software license, or a bespoke arrangement, would
need separate selection if the code is to carry the same restriction.

## GitHub-specific note

`datasets/gold/LICENSE.md` is nested, not at the repository root, so
GitHub's repository-level license detector will not read it or populate
the repo's "License" sidebar/badge from it — that detector only reliably
reads a root-level `LICENSE`/`LICENSE.txt`/`LICENSE.md`. Separately, even a
root-level copy would likely still show as undetected: GitHub's own
license-picker table lists `CC0-1.0`, `CC-BY-4.0`, and `CC-BY-SA-4.0` as
recognized identifiers, but not the NonCommercial variants, and GitHub's
license-detection tool (`licensee`) has a known open issue
(`licensee/licensee#343`) failing to identify CC-BY-NC-SA 4.0 even when
present verbatim. None of this affects the license's legal validity — the
committed file's text is what governs, regardless of whether GitHub's UI
recognizes it — it only means the repo sidebar will likely continue to
read "no license" or omit a badge. No GitHub repository *setting* needs to
change; there is no separate configuration surface for this beyond the
committed file itself.
